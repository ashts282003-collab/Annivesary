19 August 2026

Dear Future Us,

If you're reading this... then somehow, we made it here.

I don't know where we'll be when we open this again.

Maybe we'll be living somewhere we once dreamed about.

Maybe we'll have travelled to places we only talked about.

Maybe we'll have completely different dreams.

Maybe we'll still argue about the most random things. 😂

Maybe we'll still make the same stupid jokes.

Maybe you'll still steal my attention when I'm supposed to be doing something important.

A lot of things might change.

We will change too.

But I hope one thing doesn't.

I hope we're still choosing each other.

Because I don't know what our future will look like.

And honestly...

I don't want to predict it.

I just want to live it with you. ❤️

From us, to us. ❤️
